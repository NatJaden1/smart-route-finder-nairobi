# Smart Route Finder for Nairobi Traffic

## Overview

A Python application that finds the shortest route between locations in Nairobi using classic Data Structures and Algorithms.

## Data Structures
- Graph
- Priority Queue
- Hash Table

## Algorithms
- Dijkstra's Algorithm
- Breadth-First Search (BFS)

## Technologies
- Python 3
- Tkinter
